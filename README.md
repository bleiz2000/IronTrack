# IronTrack

Трекер силовых тренировок для Android: быстрый ввод подходов в зале, честная статистика и
готовность к тренировке по данным Health Connect (сон, пульс покоя, шаги).

Приложение полностью локальное: история хранится в SQLite на телефоне, никаких облаков,
аккаунтов и сетевых запросов. Всё считается на устройстве.

## Возможности

- **Быстрый ввод подхода**: вес, повторы, RPE — несколько тапов, без переключения экранов.
- **Правка и удаление подходов**: и сегодняшних, и исторических.
- **Рабочий пул упражнений**: жим лёжа, жим гантелей на наклонной, бабочка, тяга верхнего блока,
  тяга штанги к поясу, тяга гантели в наклоне, сгибания на бицепс, молотки, скамья Скотта,
  разгибания на трицепс, французский жим, махи гантелями в стороны.
- **Свои упражнения**: добавляются в один экран, с настраиваемым шагом веса.
- **Скрытие вместо удаления**: скрытое упражнение исчезает из списка, но история остаётся,
  его можно вернуть из раздела «Скрытые». Отдельно есть осознанное «удалить с историей».
- **Статистика**: посещаемость, тоннаж за 7 дней, график 1RM, лучший вес и лучший 1RM,
  последние подходы по упражнению.
- **1RM по формуле Эпли**; для одного повторения 1RM равен поднятому весу, поэтому
  одиночный жим 80 кг не теряется в расчётах.
- **Готовность к тренировке** по сну, пульсу покоя и времени с прошлой тренировки.
  Если данных нет — вес не повышается, и приложение прямо говорит, чего не хватает.
- **Health Connect**: сон и его фазы, пульс покоя, пульс, шаги, активные калории, VO2max, HRV.
  Фоновое обновление раз в час.
- **Экспорт и импорт JSON**: вся история и health-снимки переносятся одним файлом.
- **Тёмная тема**, адаптивная иконка с монохромным слоем для Material You.

## Health Connect и Mi Fitness

IronTrack не обращается к Mi Fitness напрямую — он читает данные, которые браслет и
приложение производителя передают в Google Health Connect.

1. В Mi Fitness включите передачу в Health Connect: профиль → данные третьих сторон → Health Connect.
2. В IronTrack нажмите «Разрешить Health Connect» и отметьте нужные типы данных.
3. Для фонового обновления раз в час включите строку «Фон: обновление выключено»
   в карточке «Восстановление».

Подробности и разбор проблем: [docs/health-connect.md](docs/health-connect.md).

Важно: если Mi Fitness не передаёт свежие записи в Health Connect, готовность останется
«нет данных» и вес будет удержан. Приложение не выдумывает сон и пульс.

## Сборка из исходников

Нужны JDK 17+ и Android SDK с platform 35.

```bash
./scripts/build-android.sh
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённый по ADB телефон:

```bash
./scripts/install-android.sh
```

Тесты математики:

```bash
./gradlew :core:test
```

## Структура проекта

```
app/                 Android-приложение: Compose UI, Room, Health Connect
  src/main/java/com/irontrack/app/
    ui/              экраны (тренировка, статистика, здоровье)
    data/local/      Room-база, DAO, репозиторий, миграции
    health/          чтение Health Connect и фоновая синхронизация
core/                чистая Kotlin-логика: 1RM, тоннаж, готовность; покрыта тестами
data/                исходные заметки о тренировках и выгрузки в JSON
docs/                описание базы и настройки Health Connect
scripts/             сборка, установка, конвертация заметок
```

История из заметок (45 тренировок, 718 подходов, 3 зала) лежит в `app/src/main/assets/history.json`
и подмешивается в базу при первом запуске. Это данные автора проекта — их можно удалить
или заменить своим импортом, если приложение нужно для личного дневника.

## Ограничения

- Health Connect отдаёт сон и пульс только если Mi Fitness/браслет действительно их синхронизирует.
- Training Load нет в стандартном Health Connect; IronTrack показывает тоннаж своих тренировок
  и VO2max, если он доступен.
- Калории для похудения не считаются: для этого нужны вес, рост, возраст и цель.
- Это не медицинское приложение и не замена тренеру.
