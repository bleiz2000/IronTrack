# IronTrack — план

## Сделано

- [x] **Брендинг.** Приложение и пакет: `IronTrack`, `com.irontrack.app`; английское имя в манифесте, интерфейсе и Gradle-проекте.
- [x] **Иконка.** Adaptive Icon с отдельными слоями для светлой/тёмной темы и monochrome для Material You.
- [x] **Рабочий пул упражнений.** 12 упражнений вместо армейского жима, становой, приседаний и подтягиваний.
- [x] **Кастомные упражнения.** Быстрый список упражнений во время тренировки: тап — выбрать, долгое нажатие — скрыть, удалить или удалить вместе с историей, «Добавить» — своё упражнение.
- [x] **Редактирование.** Правка и удаление сегодняшних и исторических подходов.
- [x] **1RM.** Для одного повторения 1RM равен весу; одиночный жим 80 кг учитывается. В статистике видны лучший вес и лучший 1RM.
- [x] **Статистика.** Группировка старых названий по рабочим упражнениям, посещаемость, тоннаж за 7 дней, график 1RM.
- [x] **Health Connect.** Чтение сна, фаз, пульса покоя, пульса, шагов, калорий, VO2max и HRV.
- [x] **Готовность.** Расчёт по сну, пульсу покоя и времени после тренировки; без данных — удержание веса.
- [x] **UI.** Тёмная тема, спокойная типографика, нижняя навигация, быстрый ввод RPE.
- [x] **Сборка и тесты.** `./gradlew :core:test :app:assembleDebug` проходит.
