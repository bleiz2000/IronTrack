# Черновик разбора заметок и файлы для приложения

## `workout-history.json`

Промежуточный документ со схемой `workout-tracker-data` версии 1. Содержит тренировки, упражнения, подходы, исходные строки и пометки о сомнительных местах.

Даты без года восстановлены по хронологии записей: поле `date_status` равно `inferred_year`. Такие даты стоит проверить, но они нужны, чтобы история была пригодна для приложения.

## `workout-history.md`

Читаемая версия той же истории: дата, зал, упражнение и подходы в виде `вес×повторы`.

## `workout-backup.json`

Файл для импорта в Android-приложение: формат `workout-tracker-backup` версии 1, все веса в килограммах. Создаётся скриптом:

```bash
python3 scripts/to_app_backup.py
```

Импорт в приложении заменяет текущую локальную базу. Перед импортом сделайте экспорт, если в приложении уже есть нужные записи.

## Повторная генерация

```bash
python3 scripts/convert_notes_json.py
python3 scripts/to_app_backup.py
```

`convert_notes_json.py` не меняет исходную заметку. Он сохраняет неоднозначные фрагменты в `notes`/`source_text`, а не пытается выдать догадку за факт.
