# IronTrack

Локальный тренировочный дневник для Android. Все данные хранятся на телефоне, интернет для расчётов не нужен.

## Что работает

- 12 упражнений в рабочем пуле: жим лёжа, жим гантелей на наклонной, бабочка, тяга верхнего блока, тяга штанги к поясу, тяга гантели в наклоне, сгибания на бицепс, молотки, скамья Скотта, разгибания на трицепс, французский жим, махи гантелями в стороны.
- Быстрый список упражнений во время тренировки: тап — выбрать, долгое нажатие — скрыть или удалить, «Добавить» — своё упражнение с шагом веса.
- Удаление с историей: отдельное подтверждение, подходы и статистика упражнения удаляются безвозвратно. Обычное удаление сохраняет историю и просто скрывает упражнение.
- Быстрый ввод подхода: вес, повторы, RPE в один тап, запись подхода.
- Правка и удаление подходов: нажми на строку в «Сегодня» или в «Последних подходах» статистики.
- Статистика: посещаемость, тоннаж за 7 дней, график 1RM, лучший вес и лучший 1RM, последние подходы.
- 1RM по Эпли; для одного повторения 1RM равен поднятому весу, поэтому одиночные 80 кг не теряются.
- Health Connect: сон, пульс покоя, пульс, шаги, активные калории, VO2max и HRV. Ручной ввод сна и отдыха убран.
- Экспорт и импорт JSON.
- Тёмная тема и адаптивная иконка с монохромным слоем для Material You.

## Сборка APK

Нужны JDK 17+ и Android SDK с platform 35. В проекте есть Gradle Wrapper.

```bash
./scripts/build-android.sh
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Установка на подключённый телефон:

```bash
./scripts/install-android.sh
```

## Первый запуск

История из заметок (45 тренировок, 718 подходов, 3 зала) добавляется в базу автоматически, без удаления уже записанных данных. Упражнения и залы сопоставляются по названию.

## Health Connect и Mi Fitness

IronTrack не обращается к Mi Fitness напрямую: он читает данные, которые Mi Fitness передаёт в Google Health Connect. В Mi Fitness включите синхронизацию с Health Connect, затем в IronTrack нажмите «Разрешить Health Connect» на экране «Перед подходом».

Подробности: `docs/health-connect.md`.

## Основные команды

```bash
# сборка
./scripts/build-android.sh

# установка
./scripts/install-android.sh

# тесты математики
./gradlew :core:test

# пересобрать JSON из заметок
python3 scripts/convert_notes_json.py
python3 scripts/to_app_backup.py
```

## Ограничения

- Health Connect отдаёт сон и пульс только если Mi Fitness/браслет действительно их синхронизирует.
- Training Load нет в стандартном Health Connect; IronTrack показывает тоннаж своих тренировок и VO2max, если он доступен.
- Если данных о сне и пульсе нет, готовность не выдумывается: приложение держит вес.
- Калории для похудения не считаются: для этого нужны вес, рост, возраст и цель.
